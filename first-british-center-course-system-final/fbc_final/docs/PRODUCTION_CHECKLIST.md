# Production checklist

- [ ] HTTPS active and HTTP redirected.
- [ ] Strong unique ADMIN_PASSWORD.
- [ ] Production DB user has only the required database permissions.
- [ ] `.env` is not web-accessible.
- [ ] Storage directories are outside web root.
- [ ] Demo trainer removed/replaced.
- [ ] Real levels and course definitions loaded.
- [ ] Trainer availability loaded.
- [ ] Official holidays for the active academic period loaded by Admin.
- [ ] Course sessions/week and times verified.
- [ ] Student enrollments verified.
- [ ] Simulation reviewed before first publication.
- [ ] Daily DB backup configured.
- [ ] Off-site encrypted backup configured.
- [ ] Google OAuth callback tested.
- [ ] OCR tested with the center's actual registration forms.
- [ ] LiveKit integration credentials added only if/when classroom integration is enabled.
